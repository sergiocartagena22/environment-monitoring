# Project Milestones

## Milestone 1 - DHT11 Sensor
- Read temperature and humidity using DHT11 sensor
- Print values to Serial Monitor
- Connected 16x2 LCD over I2C
- Displayed temperature and humidity values on the 16x2 I2C LCD
- Integrated the LCD using I2C communication

## Milestone 2 - Light Sensor
- Read light intensity using photoresistor
- Converted ADC readings into light percentage
- Print values to Serial Monitor
- Displayed light intensity and ADC values on the LCD
- Integrated alongside the DHT11
